# Execution evidence

Cloud readiness, initial recovery and changed-form/withheld files describe actual
Render Free execution. Files named `local-*` and the generation probe describe
development rehearsals; they do not claim hosted qualification. The final hosted
follow-up proof is captured separately after the approved update and real mail
loop finish.

Public summaries omit private case, run, operation, client-reference and payload
digest lookup identifiers, receiving capability URLs, tokens and report values.
They retain observed match booleans, process/attempt identifiers, counts and safe
ticket/receipt IDs. Full owner-only proof is retained outside Git.

Earlier revisions of two local synthetic rehearsal artifacts included receiving
lookup tuples. Those cases contained no real resident contacts, and their app
automation is cancelled. Cancellation does not revoke historical receiving
capabilities. This was test-only exposure; no Git history rewrite was performed.
Current hosted lookup identifiers remain private.

The procedural lesson is explicitly labelled `seeded_demo`: a separate, approved
manual event-day browser calibration supplied genuine update-receipt evidence.
Runtime changed-form execution requires native Atlas retrieval and a validated
generation-model mapping. An acknowledgement proves reporting progress, not a
physical repair.
