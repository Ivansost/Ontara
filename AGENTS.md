# Ontara

This is Ivan and Faaris's original Agents in Context Toronto Track 3 project.
Planning context is maintained separately in `/Users/ivan/Desktop/AI-Slop/MongoDBHacks`:
read its `AGENTS.md`, `HACKATHON_CONTEXT.md`, `MEGA_PLAN.md`, and `MVP.md` before changing scope.

Build the button-based web journey first using React 19+ and Astryx. Nine categories
are navigable; only explicitly configured Roads and Graffiti demo routes may collect
reports. Seven inactive categories must reject intake server-side. The two receiving
portals are controlled demos, not established municipal integrations.

Use the event Atlas Sandbox for data, state, public procedural knowledge and verified
experience. Native Atlas Automated Embedding with Voyage Large and scoped Vector
Search are required. Private cases and correspondence must never enter shared memory.
Keep approved versions immutable, reconcile uncertain external writes before retrying,
and distinguish attempted actions, verified receipts and actual repair.

Secrets stay outside source. Render hosting is Free only, execution is in the cloud,
and the Mac is the presentation device. Agent Engine with a small LangGraph workflow
is selected; the documented cloud fallback requires explicit evidence, not simulation.

Multiple workers own separate paths. Preserve others' work and coordinate shared
contracts. The coordinator alone serializes commits, pushes, merges and deployments.
